# ShareSpace

A calm, dark, real-time room MVP built with Next.js App Router, TypeScript, Tailwind, Zod, Vitest, and Playwright.

## Run it

```bash
npm install
npm run dev
```

Open `http://localhost:3000`. Room CRUD is available at `GET/POST /api/rooms` and `GET/PATCH/DELETE /api/rooms/:roomId`.

Run checks with `npm run lint`, `npm run typecheck`, `npm test`, and `npm run build`. See [docs/DEPLOYMENT.md](docs/DEPLOYMENT.md) for Redis and WebRTC production notes.
